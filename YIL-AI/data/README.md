# Données

Le dépôt ne contient pas les fichiers FAA SDR bruts ni le jeu nettoyé complet.
`sample_reports.csv` fournit seulement trois textes synthétiques pour essayer
l'interface.

Les données annuelles officielles peuvent être téléchargées depuis la page
[Service Difficulty Reports de la FAA](https://www.faa.gov/av-info/download_SDR).
Le référentiel utilisé pour la cible est le
[code JASC de la FAA](https://www.faa.gov/sites/faa.gov/files/JASC_Code.pdf).
